Задеплой iptvs. Аргументы: $ARGUMENTS

Деплой выполняется только этим агентом; main-сессия не копирует файлы сама. Сначала проверь свежесть сборки и спроси подтверждение. Деплой только в согласованную цель: сравнение SHA-256, backup/переименование занятых файлов, проверка результата. Не деплой молча.

Если цели не переданы — уточни их инструментом `question`. Режим закрытия/перезапуска спроси инструментом `question` для каждой цели, где приложение или служба может быть запущена. Не выбирай режим сам и не выводи его из отсутствия процессов.
